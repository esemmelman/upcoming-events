# Timeline

A small browser app for tracking items and their end-date timelines. Version 1.0.0 uses the `upcoming_events_items_v1` table in the `bnaimitzvah` Supabase project.

Hosted app: https://esemmelman.github.io/upcoming-events/

## Run it on Windows

Double-click `index.html`, or right-click it and choose **Open with** followed by your preferred browser.

No installation is required. Events are saved to Supabase and shared by everyone who opens the site. Authentication is intentionally not enabled.
